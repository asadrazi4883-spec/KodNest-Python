# Programming vs Programming Language

## What Is Programming?
it is process of creating instructions to solve a problem using a computer.

## What Is a Programming Language?
A programming language is a formal language used to communicate instructions to a computer.

## What Is Python?
Python is a high-level programming language used to develop applications, automate tasks, analyse data and build AI/ML models.

## What Is Syntax?
Syntax refers to the rules for writing statements in a programming language.

## Programming and Python
Programming is the complete problem-solving process, whereas Python is one language used to implement programming solutions.

## What Remained the Same?
- Problem
- Inputs
- Outputs
- Eligibility rules
- Logic
- Sequence of steps

## What Changed?
- Python keywords
- Operators
- Indentation
- Colons
- Print function

## My Final Understanding

Programming helps me: Understand problems and develop logical solutions.

Python helps me: Convert logical solutions into executable code.

Syntax tells me: How to write code correctly using Python rules.
